# IT 트렌드 카드뉴스 AI 비서

Hacker News 인기 글로 IT 화제도 시계열을 쌓고, 그 요약을 GPT에 주입해 트렌드 질문에 답하며, 매일 한국어 카드뉴스를 웹과 디스코드에 올리는 AI 비서.
코디세이 미션 "8_AI Agent 개발: 나만의 AI 비서 구축" 결과물.

> 개발 중. 설계는 [docs/PLAN.md](docs/PLAN.md) 참고.

## 기술 스택

FastAPI · Pydantic · Firebase Firestore · OpenAI SDK(GPT) · 바닐라 HTML/CSS/JS · Render · Vercel · Discord Webhook · GitHub Actions
